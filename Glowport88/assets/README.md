# Original assets

- `city-atlas.png`: deterministic original material and prop artwork, with coordinates in `atlas.json` / `atlas.js`.
- `characters.png`: 12 outfit palettes × 4 directions × 8 poses. Cells 32×40. Columns: idle, four walk poses, aim, recoil, reload. Rows: outfit × down/left/right/up.
- `vehicles.png`: 8 paint schemes × 16 direction cells, 64×64. Last row is a police cruiser.
- `buildings-illustrated.png`: original generated pixel-art architectural sheet, 1536×1024, six isolated buildings, transparent background. Created for this project using the image generation tool, without sampling the supplied reference. Source rectangles are declared in `art.js`. Keep its embedded provenance metadata. Raster artwork remains editable in an image editor.
- `art.js`: asset loading, terrain composition, spatial light buckets, sprite animation, lighting, weather, interiors.
- `missions.js`: evidence chains and timed driving routes, with JSON-serializable progress.
- `activities.js`: self-contained playable arcade cabinet.
- `ui.css`: Midnight Signal presentation.

Regenerate the hand-authored material/character/vehicle atlases with `python3 tools/build_assets.py` from the project root. Python Pillow is needed for regeneration only. The illustrated sheet is checked in and is not regenerated by that command. No runtime network calls or third-party assets are needed. All these files must remain beside the HTML release.

The illustrated sheet's source direction: original non-isometric top-down/front-facing neon city architecture, a 3×2 sheet of hotel, armory, radio station, cafe, nightclub, and warehouse. Warm windows, slate/violet/teal surfaces, selective cyan/pink emission, roof equipment, foliage, signage, no roads or ground, transparent cell padding.
