# Remaining Living City work

This release is a tested development milestone. The following brief requirements are not presented as finished.

1. Continuous human playthrough of all 40 main missions, complete side arcs, every major event branch, economy/difficulty balancing, long-session physical-phone testing, and campaign duration measurement. No 10–20-hour claim is supported.
2. Safari/iPhone, Android hardware, Firefox and WebKit coverage. Playwright browser download attempts received HTTP 403 Domain forbidden in this environment; only installed Chromium ran. Speaker/headphone listening and mobile battery/audio behavior need human testing.
3. Dedicated taxi dispatch, additional delivery contracts and bespoke encounter activities beyond shared objective/timing mechanics. Twenty old encounter definitions remain, including some short incidents; deeper simulation/variation is ongoing.
4. More mission-specific NPC behavior, sustained background pursuit scenes, emergency-service arrival/medical AI, individual NPC inventories, and true persistent person-by-person narrative memory. Current encounter memory and citizen reactions are bounded lightweight systems.
5. Neighborhood and criminal-organization reputation dimensions and broader economic consequences. Public reputation, personal affinity, wanted/search state and authored flags currently drive the implemented reactions.
6. Full wardrobe/outfit shops, player stamina/health upgrade progression, safehouse item-storage UI, crew commands and tactical cover. Existing inventory, property upgrades, room recovery, driving/shooting skills and garages remain functional.
7. Dedicated distinct body sprites for all ten handling models. Vehicles currently reuse and customize the approved original sprite sheet; their mechanics differ, but they are not ten newly painted vehicle bodies.
8. Broader business simulations, map filtering, discoverable property-waypoint controls, photo assignment UI and additional original dialogue/cinematics. Journal sections are implemented; the city map keeps the established landmark/story/side/event display.
9. Further performance work using physical-device profiling, real-time soak tests, GPU/process memory measurements and richer collision/pathfinding stress cases. Current endurance measurements cover accelerated CPU updates, retained JS heap, bounded entities and terrain surfaces.
10. Native app packaging, store-policy material, signed builds, device QA and Apple/Google submission remain separate future release work. This milestone is a browser game.
