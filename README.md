# Glowport ’88 · Midnight Signal

An original open-world neon-noir browser adventure. Five connected districts, the Vee/Meridian campaign, traffic, police, conversations, interiors, and side jobs remain playable. This development pass adds a new original asset pipeline, illustrated architecture, directional character and vehicle sheets, room investigations, checkpoint deliveries, portraits, and an arcade game.

## Play

Use Python 3 from the project root:

```sh
python3 -m http.server 8000 --directory Glowport88
```

Open `Glowport88_ArtRehaul_v11.html` through your local server in a modern desktop browser. The original filename is retained for compatibility. No app dependencies, credentials, or external services are needed. Keep `assets/` beside the HTML. The self-contained release is `dist/Glowport88-Midnight-Signal.html`.

WASD / arrows move; Shift runs; E interacts; mouse aims; click or F fires; 1–5 equip; R reloads; M opens the map; J opens the journal; Escape pauses. In a car, W accelerates, S reverses, A/D steer, Space brakes, and E exits after slowing down. The pink marker follows the campaign. Cyan room markers guide investigations. Gold route checkpoints guide delivery missions. Service markers offer clinic care, diner food, motel rest, and the Dead Drop arcade cabinet.

Progress uses browser local storage under the existing save key. Existing saves initialize missing investigation/trust fields safely. Switching host/port or opening a standalone file uses a different browser storage origin. Keep a copy of browser data when moving installations.

## Develop and test

```sh
npm ci
npm test
```

Tests use Playwright and an installed Chromium at `/usr/bin/chromium`. Set `CHROMIUM_PATH` to another Chromium binary when needed. They start their own temporary server, exercise real gameplay, and write screenshots/results to `artifacts/`. See `TEST_RESULTS.md` for coverage limits.

To edit/regenerate original drawn atlases, install Pillow for Python and run `python3 tools/build_assets.py`. The illustrated architectural sheet is committed artwork; it is not regenerated by that script. To rebuild the standalone HTML and source ZIP, run `python3 tools/build_release.py`.

Editable game logic is in the HTML; rendering, missions, and the arcade are separate modules in `Glowport88/assets/`. Asset layout/provenance is documented in that directory. `ART_DIRECTION.md`, `DEVELOPMENT_LOG.md`, and `ROADMAP.md` record artistic choices and continuation priorities.

This is a substantial development milestone, not a finished commercial release. See the test report for untested campaign paths and known limitations.
