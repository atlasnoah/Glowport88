# Glowport ’88 · Midnight Signal

An original open-world neon pixel-art browser crime adventure. This gameplay overhaul retains every approved art PNG, the existing renderer, 800×450 resolution, 7200×5040 city, and 20×15 road grid.

The implemented catalogue has **40 main missions in five acts**, **20 connected side stories** for five recurring contacts, and **20 contextual encounter types**. Multi-stage objectives include ordered investigations, timed driving routes, combat, protected escorts, stealth, physical vehicle pursuits, interactive heists, police searches, branching decisions, and three endings with free roam. The phone, properties, income, garages, tuning, skills, inventory, checkpoints, and saves are connected to gameplay.

[Play the browser demo](https://atlasnoah.github.io/Glowport88/?v=0.4.0). Use **New Story** to experience the expanded campaign from the beginning; existing saves migrate without duplicate tutorial payments. The demo is a development build with touch controls and a bounded terrain cache for phones. Duration remains unmeasured; an uninterrupted human playthrough of all missions and balance tuning are outstanding.

## Play on a phone

Open [the mobile browser demo](https://atlasnoah.github.io/Glowport88/?v=0.4.0), tap **Start / Continue**, and use portrait or landscape. The left stick moves or drives; the right stick aims and fires. **INTERACT** handles people, doors, objectives and cars. **WEAPON** cycles only owned weapons. **RELOAD**, **CROUCH**, hold **SPRINT/TURBO**, and **BRAKE** work without a keyboard. Tap **PHONE** for Jobs and contacts. **EXPAND** is offered only when browser fullscreen is available; fullscreen is optional.

The game autosaves on browser background/pagehide and pauses active play. Tap Resume after returning. Room position and crouch state survive reload. Saves remain local to each browser/device; desktop progress does not automatically transfer to a phone. Avoid clearing website data if you want to keep a test save.

The phone layout and real multi-touch gestures are tested in Chromium emulation at 390×844, 844×390, and 320×568. Actual iPhones/Android devices and Safari still need hands-on testing. See [MOBILE_TESTING.md](MOBILE_TESTING.md).

## Play locally

Use Python 3 from the project root:

```sh
python3 -m http.server 8000 --directory Glowport88
```

Open `Glowport88_ArtRehaul_v11.html` through your local server in a modern desktop browser. The original filename is retained for compatibility. No app dependencies, credentials, or external services are needed. Keep `assets/` beside the HTML. The self-contained release is `dist/Glowport88-Midnight-Signal.html`.

WASD / arrows move; Shift runs; E interacts; mouse aims; click or F fires; 1–5 equip; R reloads; M opens the map; J opens the journal; Escape pauses. **P opens the phone** for Jobs, contact calls, messages, properties, and status. **C toggles crouching** for stealth. After the first six training missions, accept the next main operation through Phone → Jobs. Optional jobs temporarily suspend the current main objective and resume it afterward. Retry failed checkpoints from the story panel or Phone → Contacts. In a car, W accelerates, S reverses, A/D steer, Space brakes, and E exits after slowing down. The pink marker follows the campaign. Cyan room markers guide investigations. Gold route checkpoints guide delivery missions. Service markers offer clinic care, diner food, motel rest, and the Dead Drop arcade cabinet.

Progress uses browser local storage under the existing save key. Version 3 saves retain mission objectives, choices, endings, suspended operations, actors, police searches, inventory, property, vehicles, skills, and reward receipts. Earlier saves migrate to their corresponding expanded story chapter; completed old campaigns remain completed in free roam. Switching host/port or opening a standalone file uses a different browser storage origin. Keep a copy of browser data when moving installations.

## Develop and test

```sh
npm ci
npm test
```

Tests use Playwright and an installed Chromium at `/usr/bin/chromium`. Set `CHROMIUM_PATH` to another Chromium binary when needed. They start their own temporary server, exercise real gameplay, and write screenshots/results to `artifacts/`. See `TEST_RESULTS.md` for coverage limits.

**Preserve the approved artwork.** Asset regeneration is optional and is not part of setup or this gameplay overhaul. For an explicitly authorized art task, install `tools/requirements-art.txt` for Python (the prepared environment already has Pillow 12.3.0) and run `python3 tools/build_assets.py`. The illustrated architectural sheet is committed artwork; it is not regenerated by that script. To rebuild the standalone HTML and source ZIP, run `python3 tools/build_release.py`.

The HTML hosts movement, combat, traffic, and rendering integration; mission-engine, campaign, side-content, gameplay, police-system, progression, phone, art, and arcade modules live in `Glowport88/assets/`. Asset layout/provenance is documented in that directory. `ART_DIRECTION.md`, `DEVELOPMENT_LOG.md`, and `ROADMAP.md` record artistic choices and continuation priorities.

This is a substantial development milestone, not a finished commercial release. See the test report for untested campaign paths and known limitations.
